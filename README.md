# Estudos de Lógica de Programação e Python

Este repositório reúne exercícios, projetos e práticas desenvolvidos durante meus estudos de lógica de programação e Python.

O objetivo é registrar meu aprendizado, desenvolver meu raciocínio lógico, aprimorar minha capacidade de resolução de problemas e construir uma base sólida em programação.

## Conteúdos

- Fundamentos da programação
- Variáveis e tipos de dados
- Entrada e saída de dados
- Operadores aritméticos
- Operadores relacionais
- Operadores lógicos
- Estruturas condicionais
- Estruturas de repetição
- Algoritmos
- Fluxogramas
- Python

## Organização

Os exercícios são separados por conteúdo, e cada exercício possui, quando aplicável:

- Código-fonte;
- Fluxograma;
- Descrição do problema;
- Lógica utilizada;
- Conteúdos praticados.
